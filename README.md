🏧 ATM Simulator

A beginner-level ATM Simulator project built with Python.

This project is currently a work in progress. I'm building it as a way to practice Python, GUI development, databases, and programming logic while gradually improving the project.

🚧 Status: In Progress

This project is unfinished and currently contains a basic, unpolished interface. More features, improvements, and cleanup are planned.

🛠️ Technologies
Python
CustomTkinter — GUI
SQLite — database

The project currently uses SQLite databases for storing user account information and transaction records.

📌 Current Progress

At the moment, the project includes:

Basic ATM GUI
Account number and PIN input
Initial login/authentication logic
SQLite database setup
User accounts table
Transaction records table
Basic screen management

The current GUI is intentionally a work in progress and still needs significant UI/UX improvements.

The current interface is very basic and unpolished.
